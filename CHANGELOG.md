# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - Initial Release
### Added
- Repository initialization.
- FastAPI backend with initial API routes.
- Hardware Abstraction Layers for cameras, stages, and lights.
- Mock implementations of devices for development.
- Picamera2 IMX296 driver implementation.
- Installer and bootstrapper scripts for Raspberry Pi.
- React, Vite, Tailwind CSS frontend dashboard.
